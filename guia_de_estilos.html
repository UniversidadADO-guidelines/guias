La estructura base de una página debe seguir el siguiente esquema:

<section class="mado">
  <div class="container">
    <div class="row">
      <div class="col-md-12"></div>
    </div>
  </div>
</section>

Funciones integradas

Estas funciones deben de ponerse como una clase, dentro de class="".

No importa si hay más clases, solo se deben separar por un espacio.

Código Función
align-content-center Justificar elementos al centro de manera vertical

Este elemento debe de ir como clase junto a row.
justify-content-center Justificar elementos al centro de manera horizontal

Este elemento debe de ir como clase junto a row.

Sus otros valores con justify-content-end para justificar a la derecha y justify-content-start para forzar la justificación a la izquierda
mt-5 Margen superior Tiene valores del 1 al 5 (mt-1, mt-2, etc).
mb-5 Margen inferior Tiene valores del 1 al 5 (mt-1, mt-2, etc).
text-center Centrar texto Solo funciona para texto, no para elemento (para elementos, ver justify-content-center)
hidden Ocultar elemento Solo hace invisible el elemento, no lo elimina. Muy util cuando algún contenido no se desea mostrar todavía
rounded-circle Máscara circular para imagen

Debe de estar como clase dentro de , junto con img-fluid

Funciona mucho mejor si la imagen es cuadrada
no-gutters Elimina espacio entre columnas

Este elemento debe de ir como clase junto a row y afectará a todas las columnas en esa fila.
shadow Sombra

Funciona mejor si se pone como clase en un <div> o en <img>

Sus otros valores con shadow-lg para sombra más larga y shadow-sm para sombra corta

Logotipos

Para usar estas imagenes hay varios puntos a tomar en cuenta:

  • La imagen intentará ser del 100% del ancho de su contenedor. El valor de --w limita ese tamaño.
  • --h controla la altura y es independiente del ancho, aunque influye en la manera en que la imagen se despliega
  • Adicionalmente a las clases base, se pueden user las clases negativo (para la aplicación de fondo oscuro del logo) y wip que colocará un recuadro en el área del logo para poder observar la caja contenedora y ajustar más fácilmente el tamaño.
  • Si se agrega la clase redux, se usará la versión compacta del logo
  • Se recomienda que el div para el logo esté solo en su contenedor para evitar comportamiento extraño del texto.
Estas clases funcionan aún si section no tienen la clase base de la Escuela Funcional. Esto está diseñado así para poder usar los logos fuera del contexto de la Escuela Funcional, por ejemplo en un footer o header de otra sección de la plataforma. 
<section class="mado">
  <div class="container">
    <div class="row">
      <div class="col-md-12">
        <div class="logo uado" style="--w:500px; --h:200px;"></div>
      </div>
    </div>
  </div>
</section>
